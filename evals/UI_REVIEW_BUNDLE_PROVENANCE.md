# UI check sample

UI_REVIEW_BUNDLE.json is the actual export downloaded by the final isolated
Chrome UI checker. It contains invented fixtures and the checker's own
activity. It is not the exact session filmed for the product video and is
not proof of a payment or delivery to a real payer.

RECORDED_SCENES.json describes the separate real app recording before
editing/retiming. Ephemeral recording paths are omitted.
