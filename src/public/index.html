What this does, and does not do

Oweleaf brings invoice status, a reminder draft and your wait decision into one review. It does not read your email, discover a client's reply, collect money, or fix a client's payment process. If a client replied elsewhere, add a wait note here. No automatic sending.

The watcher runs only while this local server is open. This is a prototype, not a production security certification. Read the measured model results.
